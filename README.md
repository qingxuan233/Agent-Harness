## 1. 这是什么 / 怎么用

本体系解决 AI Agent 参与开发时的四类失效：**上下文错乱、幻觉、过度自信、知识流失**。
初版基于本地五项目与 Agent 领域开源调研；v1.2 新增的项目推进治理条款基于单独核实的开源原文，入口见 [03-project-delivery.md 末尾](03-project-delivery.md) 和 [90-reference-and-templates.md 附录 D](90-reference-and-templates.md)。v1.3 起全部文档按 [§1.3 文档命名规范](01-core-spec.md) 命名：序号 + 小写 ASCII kebab-case。

**按你的角色选入口**：

| 你是 | 先读 | 用途 |
|---|---|---|
| 第一次接触本项目 | 本文件 §2 阅读路径 | 搞清有什么、从哪开始 |
| 要给新项目立规范 | [`90-reference-and-templates.md`](90-reference-and-templates.md) 附录 A1 | 直接复制 AGENTS.md 骨架 |
| 要给存量项目补规范 | [`01-core-spec.md`](01-core-spec.md) §10 | 三层渐进迁移法 |
| Agent 接到具体任务 | [`02-agent-workflow.md`](02-agent-workflow.md) | SOP 全流程 |
| 遇到上下文/幻觉/自信问题 | `01-core-spec.md` §4 / §5 / §6 | 对应机制 |
| 要沉淀踩坑、归档文档 | `01-core-spec.md` §7 / §8 / §9 | 制度与模板 |
| 要管分支、版本、安全 | [`02-agent-workflow.md`](02-agent-workflow.md) §3.11~§3.13 | 分支治理 + 变更安全 |

## 4. 版本增量与重要补强

### v1.1：Agent 工作治理

- 修复 AGENTS.md 容量红线矛盾，采用三档分级；将超限规范拆分，避免静默截断。
- 新增分支/规范版本/安全、代码评审/测试、上下文截断、提示词治理、Agent 回归、多 Agent 冲突处置。

### v1.2：项目推进与交付治理

| 新增 | 位置 | 解决的推进风险 |
|---|---|---|
| 风险分级 + DRI/责任矩阵 | [03 §2~§3](03-project-delivery.md) | 避免小改重流程，也避免高风险事项无人负责 |
| 需求基线 + 变更影响评估 | 03 §4 | 控制范围漂移、验收口径移动和返工 |
| 阶段门 G0~G7 | 03 §5 | 让项目有明确继续/暂停/签核条件 |
| 用户结果/无障碍验收 | 03 §6 | 防止只有开发者自证、技术正确但用户无法完成任务 |
| 发布就绪/观测/runbook/Go-No-Go | 03 §7 | 防止“本地构建通过”却无法在目标环境安全运行 |
| 兼容矩阵/渐进弃用/升级顺序 | 03 §8 | 降低多版本、多个消费者和数据 schema 升级风险 |
| 数据生命周期与隐私风险 | 03 §9 | 补齐超出密钥本身的个人/业务数据治理 |
| SBOM/许可证/构建来源证明 | 03 §10 | 把供应链与许可问题提前到发布前发现 |
| Continue/Pivot/Stop 里程碑复核 | 03 §11 | 避免沉没成本导致无价值项目持续消耗资源 |

## 5. 维护规则

1. **谁写谁登记**：新增/移动文件必须同步更新本表 §2 与对应索引。
2. **命名先于内容**：新文件名必须符合 [§1.3](01-core-spec.md)；重命名按 §1.3.4 原子化更新全部引用。
3. **版本语义化**（遵循 [02 §3.12](02-agent-workflow.md)）：MAJOR = 红线或规则不兼容；MINOR = 新增条款；PATCH = 澄清。
4. **改完跑校验**：至少核对 ① 文件体积未超 64KB；② 交叉引用编号存在；③ 本表 §2 与实际文件一致；④ 无断链、无旧文件名残留。
5. **废弃不删除**：标 `DEPRECATED` + 替代指针，保留一个版本周期。
6. **改动留痕**：在 `01-core-spec.md` 末尾的「v1.x 变更」行追加摘要。

## 6. 快速自检（接手任务前）

```
□ 我读过 README（本文件）与 01-core-spec.md §0.3 权威优先级吗？
□ 当前任务涉及的分支/版本/安全条款（02 §3.11~3.13）我核对了吗？
□ 我是否在遵守阅读预算（≤3 篇主题文档，>300 行文件分段读）？
□ 我新建/重命名的文件符合 §1.3 命名规则，且所有引用已同步吗？
□ 我引入的每一条结论，都能给出证据位置吗？
□ 我有没有把"没验证"说成"已完成"？
```

任一为否 → 回到对应章节，不要直接开工。
